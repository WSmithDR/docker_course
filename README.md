# 🐳 Docker Course - Practices & Environments

This repository contains my isolated practice environments to learn and assimilate Docker implementations. The project structure is designed to complement my study workflow, which relies heavily on **Active Recall** and **Spaced Repetition**.

## 🧠 Study Methodology

To ensure deep technical learning and long-term syntax retention, I use the following dynamic:

1. **Anki Prompts:** I transform course concepts, key commands, and configurations into Anki flashcards to expand my technical vocabulary and knowledge.
2. **Isolated Environments (Branches):** Each `branch` of this repository works as an independent test environment for a specific topic or exercise.
3. **Practical Implementation:** When my Anki system presents a practical card or challenge, I use the corresponding branch in my local environment (Ubuntu) to solve the prompt by writing the necessary `Dockerfile` or `docker-compose.yml` files.
